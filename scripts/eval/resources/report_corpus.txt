# Radiology report corpus for dictation evaluation.
#
# Purpose-written for this harness. Each block below is one report, separated
# by a blank line; lines starting with '#' are ignored. The text is spoken by
# an offline synthesiser (scripts/eval/build_sets.py) to produce the `tts` gold
# set, and doubles as the reading script for the `own` set.
#
# Why written rather than sourced: public radiology corpora (Open-i, MIMIC-CXR)
# carry non-commercial / no-derivatives terms or credentialed access, and none
# of them guarantee coverage of THIS project's curated radiology_lexicon.txt.
# These reports are written to hit that lexicon densely and on purpose, so the
# medical-term error rate is measured against the exact vocabulary the
# correction pipeline claims to protect.
#
# These are synthetic. They describe no real patient and must never be quoted
# as clinical material.
#
# When adding a report: keep it 40-90 words (roughly 20-40 seconds spoken),
# write it the way it would actually be dictated, and prefer terms that appear
# in src/resources/radiology_lexicon.txt.
